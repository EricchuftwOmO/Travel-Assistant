TableStatusDescription
usersimplementedStores user accounts: name, email and a bcrypt password hash.
tripsimplementedStores each trip: title, destination and dates. Every trip belongs to one owner.
itinerariesimplementedOne row per travel day of a trip, kept in step with the trip's dates.
placesimplementedStores the places that can be added to an itinerary, by city and category.
itinerary_itemsimplementedStores the places scheduled for each day and their visit order (positions start at 1).
trip_membersplannedTracks which users belong to each trip.
trip_flightsplannedStores flight information associated with each trip.
expensesplannedRecords trip expenses, including amounts and who paid.
expense_splitsplannedTracks how each expense is split among trip members.
